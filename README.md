# ai-algorithms-collection

Собрание классических алгоритмов искусственного интеллекта, реализованных на **CLIPS** и **C++**.

## Структура проекта

```text
ai-algorithms-collection/
├── README.md
├── .gitignore
├── clips-experts/
│   ├── animals.clp
│   └── food-selection.clp
├── graph-search/
│   ├── main.cpp
│   ├── edges.txt
│   └── heuristics.txt
└── game-tree/
    └── main.cpp
```

## Модули

### 1. clips-experts/ - Экспертные системы (CLIPS)

Две диагностические системы на правилах, написанные на CLIPS. Используют прямой вывод и задают пользователю серию вопросов для получения заключения.

| Файл | Описание |
|------|----------|
| animals.clp | Определяет животное по способу передвижения, типу крыльев, рациону и окрасу. |
| food-selection.clp | Подбирает блюдо по типу приёма пищи, наличию времени на готовку и вкусовым предпочтениям. |

Как запустить:
1. Установите CLIPS 6.4 или новее.
2. Откройте нужный файл .clp в среде CLIPS.
3. Выполните команды (reset) и (run).

---

### 2. graph-search/ - Поиск пути (C++)

Интерактивное консольное приложение для поиска кратчайшего пути во взвешенном ориентированном графе с использованием двух алгоритмов:

- A* - эвристический поиск с использованием оценок вершин из heuristics.txt.
- Муравьиная колония - вероятностный поиск, имитирующий поведение муравьёв и феромонные следы.

Возможности:
- Пошаговый протокол поиска (раскрытые / нераскрытые вершины).
- Настройка размера колонии для муравьиного алгоритма.
- Вывод итогового кратчайшего пути и его суммарного веса.
- Ввод графа произвольного размера (вершины и рёбра).

Как запустить:
cd graph-search
g++ main.cpp -o graph-search
./graph-search

Формат входных данных:
- edges.txt - каждая строка: начало конец вес
- heuristics.txt - по одному значению на строку (эвристическая оценка для каждой вершины)

---

### 3. game-tree/ - Минимакс и альфа-бета отсечение (C++)

Реализация двух алгоритмов поиска на игровом дереве с возможностью изменять оценки листьев и порядок ходов игроков (MAX / MIN).

Возможности:
- Изменение оценок листьев в интерактивном режиме.
- Выбор порядка анализа (слева-направо или справа-налево).
- Вывод промежуточных оценок всех узлов дерева.
- Демонстрация классического минимакса и альфа-бета отсечения.

Как запустить:
cd game-tree
g++ main.cpp -o game-tree
./game-tree

---

## Требования

- CLIPS 6.4+ - для файлов .clp.
- Компилятор C++17 - g++, clang++ или MSVC 2019+.
- Внешние библиотеки не требуются.
